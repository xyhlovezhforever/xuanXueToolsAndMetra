# 玄览专题模块

本目录提供小渐知你主应用中“资料”与“工具”板块下的玄览专题页面。它随主应用一起由 Vite 构建，AI 接口由主应用的 `server.mjs` 提供；请从项目根目录运行和测试。

## 内容

- 先天八卦的序数、方位与象义
- 六十四卦卦辞与入门白话提示
- 小六壬六宫、掌诀、三步起法、当前时间快速起卦与 AI 解读
- Rider Waite 体系 78 张塔罗牌义
- 三组三位数字起卦、本卦与之卦的 AI 分析

数字起卦依次输入下卦、上卦、动爻各一组三位数字（`000` 至 `999`）。前两组除以 8，第三组除以 6；余数为 0 时分别按 8 或 6 计。八卦采用先天序数：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。动爻从下往上数，仅变这一爻得到之卦。例如 `008`、`006`、`006` 得水地比，上六动，之卦为风地观。

AI 分析会把三组数字、卦象和填写的问题发送至配置的模型服务。密钥仅保存在主项目根目录的 `.env.llm.local.toml`，由服务端读取。

小六壬的 AI 解读在快速起卦后由用户主动触发。服务端按提交的时间与时区重新计算月宫、日宫和时宫，再结合所问之事生成文化学习角度的分析。

小六壬快速起卦按浏览器当地时间换算农历月份、日期与时辰。闰月沿用原月序数；23:00 起为子时，但农历日期不提前换日。不同传承可能采用不同口径。

# 玄枢

面向风水师、术数从业者和传统文化学习者的综合资料与排盘工作台。

项目将资料检索、基础查表与可复现计算分成三个工作区。不同流派、版本和算法口径保持独立标注，不把互相冲突的规则强行合并为一个结论。

## 已实现

- 13 个资料门类与 72 篇核心条目
- 全局搜索、难度筛选、收藏和最近阅读
- 六十四卦、二十四山、天干地支与八卦万物查表
- 黄历、八字、紫微、六爻、梅花、奇门、六壬、太乙等 15 个计算工具
- 黄历和八字友好表单
- 其他术式的模式校验与专家参数编辑器
- 深浅主题与移动端布局
- Playwright 桌面和手机端自动化测试

## 技术栈

- React 19
- TypeScript
- Vite
- Express
- taibu-core
- Phosphor Icons
- Playwright

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

前端默认运行在 `http://127.0.0.1:5173`，本地计算接口运行在 `http://127.0.0.1:8787`。

## 生产构建

```bash
npm run build
npm start
```

## 验证

```bash
npm run lint
npm run test:ui
```

## 使用边界

本项目用于传统文化学习、资料检索与咨询记录。术数计算结果不构成医疗诊断、法律意见、投资建议或安全保证。涉及健康、安全、法律和重大财务决策时，应优先采用相应专业意见。
